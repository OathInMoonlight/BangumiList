# BangumiList

这是一个将表格可视化的小程序，在常规表格的基础上添加了一些小功能

[日本語](https://github.com/OathInMoonlight/BangumiList/blob/main/README_ja.md) [English](https://github.com/OathInMoonlight/BangumiList/blob/main/README_en.md)

- 为每一行内容添加了**图片**，并可以在**网格试图**中展示
- 支持**双层表格**的**嵌套**，每一行内容都映射到一个内部的表格
- 支持搜索、排序以及**分类排序**

# 下载

本程序的运行需要系统级WebView的支持（通常不需要额外操作）

# 使用说明

## 语言和设置

![image](https://github.com/user-attachments/assets/b0b7b289-04c2-462e-9859-e914eab5fdf9)

### 语言

在程序的左下角①有语言选单，点击切换语言

目前仅支持`[中文, 日本語, English]`

### 设置

点击左下角齿轮图标②即可打开设置界面

1. **全局缩放**③：调整界面整体的缩放值，优先建议调整程序本体的**兼容性**处改变**DPI**设置
>已知问题：部分浮动界面可能无法随全局缩放值更改缩放
2. **深色模式**④：调整界面背景的模式，默认为跟随系统
3. **主色调**⑤：调整按钮等关键处的颜色，提供了部分基于Material Design的颜色
4. **是否保存设置文件**⑥：开启后将会自动将语言和设置保存在程序根目录的`bangumilist_setting.json`文件下，其格式为：
```json
{
    "language":"zh"|"ja"|"en",
    "globalZoom":1,
    "theme":"system"|"dark"|"light",
    "primaryColor":"#2196F3"
}
```

## 数据库操作

### 打开一个数据库

![image](https://github.com/user-attachments/assets/9e81711d-76b7-4e82-874c-99764d55ee4b)

打开一个现存的数据库`*.bldb`有3种方式：

- 单击中央的虚线区域，然后再系统的文件选择器中选择数据库打开
- 在系统的文件资源管理器中找到数据库，然后将其拖拽到虚线区域
- 直接在系统的文件资源管理器中双击打开`*.bldb`文件

### 新建或编辑一个数据库

![image](https://github.com/user-attachments/assets/7339de30-4c46-49a2-bd45-8c00fb7ea230)

当你单击新建数据库①或者编辑数据库②时，会切换到编辑数据库界面

#### 数据库设置

- **网格视图**③：你可以选择是否开启网格视图功能，开启后将强制在主表和子表（如果有）的第2列插入一个封面列。该列为文本段落格式，保存一个图片的的链接。如果有子表，则主表插入的列为数字格式，保存显示哪个子表图片的序号。
- **双层表**④：你可以选择是否开启双层表嵌套功能，开启后将会添加一个子表，每一个主表项都会对应拥有相同列格式但不同内容的子表。

#### 主表设置/子表设置

- 最下面的加号图标按钮⑤可以为此表增加一个列
- 最左侧按钮⑥可以调整每一列的顺序，以及删除一个已经创建的列。为保证数据的安全，已经创建好的列一旦保存则不可修改其顺序或将其删除。
- **网格视图封面标签**⑦：仅针对网格试图，在网格视图的图片右下角显示某列的`布尔`值，默认为`Null`，可填入列序号。
- **网格视图标题**⑧：仅针对网格视图，在网格视图的图片下方显示标题。可填入列序号数组，可按顺序尝试显示，如若**列显示语言**或**列显示**为`false`，则自动显示下一列。

每一列都有以下选项

- **列类型**⑨：选择该列的数据类型，不得为空。可选的类型有`[布尔, 标签, 数值, 文本, 段落]`。其中，`段落`可包含换行。
- **列名**⑩：该列的显示名称，对应所有语言。若有不需要的语言，建议填入其它语言内容，最好不要为空。
- **列排序映射**⑪：在对该列进行排序时，可以使用其它列的值作为排序依据。比如本列为名称，其它列为其名称的拼写方式。默认为本列的序号，需要时可调整为其他列的序号。
- **列分组类型**⑫：指示如何对该列进行分组排序。默认值为`不分组`，暨不对该列进行分组排序。若选择`按首字母分组`，则将本列视为**文本**或**段落**，按照其首字母进行分类，符号等会被分入`#`类。若按**JSON**格式填入数组`(boolean | number | string)[]`，则按照数组内值进行分组，不属于任何一组的将会被分入`#`类。
- **列显示语言**⑬：指示该列是否仅在某种语言下显示。默认值为`不随语言显示`。
- **列值预设**⑭：为`布尔`和`标签`类型的列设置显示方式。默认值为`无值预设`，暨无特殊显示方式。若想为该列设置显示模式，则必须遵循以下**JSON**格式：
```json
{
    ["key":string]:{
        "title?":{
            "zh": string,
            "ja": string,
            "en": string
        },
        "color?": string,
        "icon?": string
    }
}
```
其中`icon`必须为一个**SVG**格式的字符串。
对于`布尔`格式，若存在`icon`则调用`icon`和`color`，不显示文字，否则调用`title`和`color`。
对于`标签`格式，则自动调用`title`和`color`。
- **列显示**⑮：指示该列是否在默认状态下显示。

## 表操作

### 工具栏

![image](https://github.com/user-attachments/assets/ef7efee1-07b5-418f-b2dc-f3d92f6adcb9)

#### 新建项目

点击加号按钮①自动进入空白的项目[编辑模式](#编辑模式)

#### 导入

点击②导入一个`*.csv`文件，其必须遵顼以下格式：

- 第一行为表头，读取时会自动跳过
- 从第二行开始到最后一行将会被导入，每一行视为一个主表项
- 子表有两种格式：
    - 和实际`*.bldb`相同，在主表的第3列以**JSON**格式文本保存
    ```
    主表列1,主表列2（子表JSON）,主表列3
    1,"[{"0":1,"1":"子表第1行"},{"0":2,"1":"子表第2行"}]","主表第1行"
    ```
    - 跳过第3列，从主表的最后一列之后开始展开子表列，子表列将会被展开最大子表项数次
    ```
    主表列1,主表列2,子表列1,子表列2,子表列1,子表列2
    1,"主表第1行",1,"子表第1行",2,"子表第2行"
    ```

请在导入前确认：

1. 导入文件格式为UTF-8(.csv)
2. 导入内容已删除空行和空列，非空行有序号
3. 各列顺序以及数据格式同当前数据库一致

#### 导出

点击③进入导出模式

![image](https://github.com/user-attachments/assets/afc8939d-a44b-434c-8191-bf25843a63a7)

1. **导出语言**④：导出的`*.csv`文件表头所用语言，仅供显示用。
2. **展开子表**⑤：选择是否对子表列进行展开，如展开则将子表列排在主表列后面，参见[导入](#导入)

### 视图栏

右上角的按钮组可以切换视图模式

![image](https://github.com/user-attachments/assets/0bb4e62d-9566-4cba-9a79-6983422fb1ae)

- **网格视图**①：仅针对开启了网格视图的数据库，将每行数据展示为一个图片。图片由[网格视图封面标签](#主表设置子表设置)指定，图片下方的标题文字则由[网格视图标题](#主表设置子表设置)指定。
    - **操作逻辑**：未开启子表时，点击图片进入到查看其内容的[查看模式](#查看模式)。开启子表时，在主表点击图片则会进入到其对应的子表，同时在子表点击图片则会正常进入**查看模式**，要修改主表对应的内容，需点击右上角的眼睛图标②进入其对应的**查看模式**。
    - **网格大小**：右上角的网格按钮组③可以切换图片的大小。这只会改变图片的大小，要更改UI的比例，请调整[全局缩放](#设置)。
    - **排序**：网格大小左侧的下拉选择框④可以选择排序的方式，每一列都分为升降两种。
    - **分组排序**：排序选择框左侧的下拉选择框⑤为分组排序，默认为`不分组`。在[列设置](#主表设置子表设置)中选择了**列分组类型**时，将会提供该列的升降分组排序选项。分组时将会把同一组的图片放置于同一个折叠面板内，折叠面板默认开启。

- **表格视图**①：将数据以表格形式呈现，为呈现完整数据增加了横向滚动轴。
    - **操作逻辑**：未开启子表时，点击一行进入到查看其内容的[查看模式](#查看模式)。开启子表时，在主表点击一行则会进入到其对应的子表，同时在子表点击一行则会正常进入**查看模式**，要修改主表对应的内容，需点击右上角的眼睛图标②进入其对应的**查看模式**。
    - **排序**：点击每一列的表头以切换排序方式。默认为以`序号`列升序排序，点击某列表头一次切换到该列的升序排序，再点击一次切换到降序排列，再次点击回归默认。
    - **分组排序**：视图模式左侧的下拉选择框⑤为分组排序，默认为`不分组`。在[列设置](#主表设置子表设置)中选择了**列分组类型**时，将会提供该列的升降分组排序选项。分组时将会在所有列的左侧新增一个分组列，分组列将会把同一个分组的行合并为一行。

![image](https://github.com/user-attachments/assets/24323b91-5c88-4937-a641-eb8b0c4f1e81)

- **统计视图**①：将某一列的数据进行统计并以图表形式呈现。使用时在下拉选择框②中选择一列进行统计。
    - **数值统计**：仅针对数值列，显示该列的`[求和,最大,最小,平均]`值。
    - **柱状图**：显示该列所有值的出现频次，横轴为值，纵轴为次数。
    - **甜甜圈图**：显示该列所有制的出现比例。

### 搜索栏

在搜索栏输入值进行搜索，搜索模式为**全匹配**，每行中有一处符合全匹配则包含在搜索结果中。
输入时有150ms的防抖。

搜索栏的右侧显示了符合搜索结果的行数。

### 项目内容

![image](https://github.com/user-attachments/assets/436e452a-b1d1-4ec7-83ef-71f5e97fda04)

#### 查看模式

在[网格视图](#视图栏)下点击图片或在[表格视图](#视图栏)下点击一行进入查看模式。
在查看模式下如果该行有对应的图片则会显示在左侧的图片处①以及背景中。
该行所有列及其所对应的值在右侧纵向排列。

#### 编辑模式

在[查看模式](#查看模式)下点击右上角的铅笔图标②会进入到编辑模式，可以对该行每列对应的值进行编辑。
- `布尔`类型：将会显示为一个开关，点击开关进行切换。
- `标签`类型：将会显示为一个下拉选择框，其中在[列定义](#主表设置子表设置)的**列值预设**中包含的值将会出现在选项中，也可以自行输入值。
- `数值`类型：将会显示一个数值输入器。
- `文本`类型：将会显示一个文本输入框。
- `段落`类型：同样显示一个文本输入框，但可以包含换行。换行应直接使用键盘输入，而非使用`\n`等转义符。

#### 删除项目

在[查看模式](#查看模式)下点击右上角的垃圾桶图标③可以删除当前行。
如果当前行包含子表，则**子表会被一起删除**。
