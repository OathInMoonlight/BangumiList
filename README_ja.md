# BangumiList

BangumiListは、表を可視化するための小さなアプリケーションです。通常の表機能をベースに、いくつかの便利な機能を追加しています。
[中文](https://github.com/OathInMoonlight/BangumiList/blob/main/README.md) [English](https://github.com/OathInMoonlight/BangumiList/blob/main/README_en.md)

- 各行に**画像**を追加し、**グリッドビュー**で表示可能
- **二重テーブル**の**ネスト構造**に対応し、各行が内部テーブルに対応
- 検索、ソート、および**グループソート**に対応

# ダウンロード

本アプリケーションの実行には、システムレベルのWebViewサポートが必要です（通常は追加設定不要）。

アプリケーション本体には言語パックが含まれています。

[こちらをクリックしてダウンロードしてください。](https://github.com/OathInMoonlight/BangumiList/releases)

# 使用方法

## 言語と設定

![image](https://github.com/user-attachments/assets/b0b7b289-04c2-462e-9859-e914eab5fdf9)

### 言語

画面左下①に言語選択メニューがあります。クリックして言語を切り替えてください。

現在対応している言語：`[中文, 日本語, English]`

### 設定

左下の歯車アイコン②をクリックすると設定画面を開けます。

1. **グローバルズーム**③：画面全体の拡大率を調整します。まずはアプリケーション本体の**互換性設定**で**DPI**設定を変更することを推奨します。  
> 既知の問題：一部のフローティングUIは、グローバルズーム値に応じて拡大縮小されない場合があります。

2. **ダークモード**④：UI背景の表示モードを調整します。デフォルトではシステム設定に従います。

3. **プライマリカラー**⑤：ボタンなど主要UIの色を調整します。一部のMaterial Designベースのカラーが用意されています。

4. **設定ファイルを保存するか**⑥：有効化すると、言語と設定がアプリケーションルートディレクトリの`bangumilist_setting.json`に自動保存されます。形式は以下の通りです：

```json
{
    "language":"zh"|"ja"|"en",
    "globalZoom":1,
    "theme":"system"|"dark"|"light",
    "primaryColor":"#2196F3"
}
```

## データベース操作

### データベースを開く

![image](https://github.com/user-attachments/assets/9e81711d-76b7-4e82-874c-99764d55ee4b)

既存の`*.bldb`データベースを開く方法は3つあります：

- 中央の点線エリアをクリックし、システムのファイル選択ダイアログからデータベースを選択する
- システムのファイルエクスプローラーでデータベースを探し、点線エリアへドラッグ＆ドロップする
- システムのファイルエクスプローラー上で`*.bldb`ファイルをダブルクリックして直接開く

### データベースを新規作成または編集する

![image](https://github.com/user-attachments/assets/7339de30-4c46-49a2-bd45-8c00fb7ea230)

**データベースを新規作成**①または**データベースを編集**②をクリックすると、データベース編集画面へ切り替わります。

#### データベース設定

- **グリッドビュー**③：グリッドビュー機能を有効にするか選択できます。有効時、メインテーブルおよびサブテーブル（存在する場合）の2列目にカバー列が強制的に挿入されます。  
  この列は段落形式で、画像リンクを保存します。  
  サブテーブルが存在する場合、メインテーブルに挿入される列は数値形式となり、どのサブテーブル画像を表示するかの番号を保存します。

- **二重テーブル**④：二重テーブルのネスト機能を有効にするか選択できます。有効時、サブテーブルが追加され、各メインテーブル項目に対して同じ列構造だが異なる内容を持つサブテーブルが対応付けられます。

#### メインテーブル設定 / サブテーブル設定

- 最下部のプラスアイコンボタン⑤で列を追加できます。
- 左側のボタン⑥で列順の変更や作成済み列の削除が可能です。データ保護のため、一度保存された列は順序変更や削除ができません。

- **グリッドビューカバーラベル**⑦：グリッドビュー専用。画像右下に特定列の`Boolean`値を表示します。デフォルトは`Null`で、列番号を入力できます。

- **グリッドビュータイトル**⑧：グリッドビュー専用。画像下に表示するタイトルを指定します。列番号配列を入力でき、順番に表示を試みます。  
  **列表示言語**または**列表示**が`false`の場合、自動的に次の列が使用されます。

各列には以下の設定があります：

- **列タイプ**⑨：列のデータ型を選択します。空欄不可。選択可能な型：`[Boolean, Tag, Number, Text, Paragraph]`  
  このうち`Paragraph`は改行を含められます。

- **列名**⑩：全言語共通の表示名です。不要な言語がある場合は空欄にせず、他言語の内容を入力することを推奨します。

- **列ソートマッピング**⑪：ソート時に別列の値を基準にできます。  
  例：本列が名称、別列がその読み方や綴りの場合、別列をソート基準に指定可能です。  
  デフォルトでは自身の列番号を使用します。

- **列グループタイプ**⑫：グループソート方法を指定します。デフォルトは`グループなし`です。

  - `先頭文字でグループ化`：本列を**Text**または**Paragraph**として扱い、先頭文字で分類します。記号などは`#`グループに分類されます。
  - JSON配列形式 `(boolean | number | string)[]`：配列内の値に基づいて分類します。どのグループにも属さない値は`#`グループになります。

- **列表示言語**⑬：特定言語時のみ表示するか指定します。デフォルトは`言語に依存しない`です。

- **列値プリセット**⑭：`Boolean`および`Tag`型の表示方法を設定します。デフォルトは`プリセットなし`です。

  表示モードを設定する場合、以下のJSON形式に従う必要があります：

```json
{
    ["key":string]:{
        "title?":{
            "zh": string,
            "ja": string,
            "en": string
        },
        "color?": string,
        "icon?": string
    }
}
```

`icon`は**SVG形式文字列**である必要があります。
`Boolean`型の場合、`icon`が存在すれば、`icon`と`color`を使用し、文字列は表示しません。そうでなければ、`title`と`color`を使用します。
`Tag`型の場合、`title`と`color`が自動適用されます。

- **列表示**⑮：デフォルト状態で列を表示するか指定します。

### データベースを保存 / 名前を付けて保存

![image](https://github.com/user-attachments/assets/853c787c-97b5-4b53-9505-15702d64ca8c)

タイトルバーの丸印①が点灯している場合、**データベースを保存**②および**データベースを名前を付けて保存**③が使用可能になります。

新規作成されたデータベースの場合、保存操作は自動的に「名前を付けて保存」として動作します。

### データベースを閉じる

別のデータベースへ切り替える場合は、**データベースを閉じる**④を使用してオープンモードへ戻ることができます。

## テーブル操作

### ツールバー

![image](https://github.com/user-attachments/assets/ef7efee1-07b5-418f-b2dc-f3d92f6adcb9)

#### 項目を新規作成

プラスボタン①をクリックすると、空白の項目が自動的に[編集モード](#編集モード)で開かれます。

#### インポート

②をクリックして`*.csv`ファイルをインポートします。ファイルは以下の形式に従う必要があります：

- 1行目はヘッダーとして扱われ、自動的にスキップされます
- 2行目から最終行までがインポート対象となり、各行は1つのメインテーブル項目として扱われます
- サブテーブルには2種類の形式があります：

    - 実際の`*.bldb`形式と同じで、メインテーブルの3列目に**JSON**形式テキストとして保存する方法：

    ```
    メインテーブル列1,メインテーブル列2（サブテーブルJSON）,メインテーブル列3
    1,"[{"0":1,"1":"サブテーブル1行目"},{"0":2,"1":"サブテーブル2行目"}]","メインテーブル1行目"
    ```

    - 3列目をスキップし、メインテーブル最終列以降にサブテーブル列を展開する方法。サブテーブル列は最大サブテーブル項目数まで展開されます：

    ```
    メインテーブル列1,メインテーブル列2,サブテーブル列1,サブテーブル列2,サブテーブル列1,サブテーブル列2
    1,"メインテーブル1行目",1,"サブテーブル1行目",2,"サブテーブル2行目"
    ```

インポート前に以下を確認してください：

1. インポートファイル形式がUTF-8（`.csv`）であること
2. 空行・空列が削除されており、非空行に番号があること
3. 列順およびデータ形式が現在のデータベースと一致していること

#### エクスポート

③をクリックするとエクスポートモードに入ります。

![image](https://github.com/user-attachments/assets/afc8939d-a44b-434c-8191-bf25843a63a7)

1. **エクスポート言語**④：エクスポートされる`*.csv`ファイルのヘッダー表示言語を指定します（表示用のみ）。
2. **サブテーブルを展開**⑤：サブテーブル列を展開するか選択します。有効時、サブテーブル列はメインテーブル列の後ろに配置されます。詳細は[インポート](#インポート)を参照してください。

### ビュー欄

右上のボタングループでビューモードを切り替えられます。

![image](https://github.com/user-attachments/assets/0bb4e62d-9566-4cba-9a79-6983422fb1ae)

- **グリッドビュー**①：グリッドビューが有効なデータベースのみ利用可能です。各行を画像として表示します。  
  画像は[グリッドビューカバーラベル](#メインテーブル設定--サブテーブル設定)で指定され、画像下のタイトルは[グリッドビュータイトル](#メインテーブル設定--サブテーブル設定)で指定されます。

    - **操作ロジック**：  
      サブテーブル未使用時、画像をクリックすると内容確認用の[閲覧モード](#閲覧モード)へ入ります。  
      サブテーブル使用時、メインテーブル上で画像をクリックすると対応するサブテーブルへ移動し、サブテーブル上の画像クリックでは通常通り**閲覧モード**へ入ります。メインテーブル側の内容を編集するには、右上の目アイコン②をクリックして対応する**閲覧モード**へ入ってください。

    - **グリッドサイズ**：  
      右上のグリッドサイズボタン③で画像サイズを変更できます。変更されるのは画像サイズのみで、UI全体の拡大率は[グローバルズーム](#設定)を調整してください。

    - **ソート**：  
      グリッドサイズ左側のドロップダウン④でソート方式を選択できます。各列に昇順・降順があります。

    - **グループソート**：  
      ソート欄左側のドロップダウン⑤がグループソートです。デフォルトは`グループなし`です。  
      [列設定](#メインテーブル設定--サブテーブル設定)で**列グループタイプ**を設定している場合、その列に対する昇順・降順グループソートが利用可能になります。  
      同一グループの画像は折りたたみパネルにまとめられ、初期状態では展開されています。

- **テーブルビュー**①：データを表形式で表示し、完全な表示のため横スクロールバーを追加します。

    - **操作ロジック**：  
      サブテーブル未使用時、行をクリックすると[閲覧モード](#閲覧モード)へ入ります。  
      サブテーブル使用時、メインテーブル上の行クリックで対応サブテーブルへ移動し、サブテーブル上の行クリックでは通常通り**閲覧モード**へ入ります。メインテーブル側を編集するには、右上の目アイコン②をクリックして対応する**閲覧モード**へ入ります。

    - **ソート**：  
      各列ヘッダーをクリックしてソート方式を切り替えます。デフォルトでは`番号`列の昇順です。  
      1回目クリック → 昇順  
      2回目クリック → 降順  
      3回目クリック → デフォルトに戻る

    - **グループソート**：  
      ビューモード左側のドロップダウン⑤がグループソートです。デフォルトは`グループなし`です。  
      [列設定](#メインテーブル設定--サブテーブル設定)で**列グループタイプ**を設定している場合、対応するグループソートが利用可能になります。  
      グループ化時、全列左側に追加のグループ列が追加され、同じグループの行は1つにまとめられます。

![image](https://github.com/user-attachments/assets/24323b91-5c88-4937-a641-eb8b0c4f1e81)

- **統計ビュー**①：指定した列のデータを集計し、グラフ形式で表示します。使用時はドロップダウン②から対象列を選択してください。

    - **数値統計**：  
      数値列のみ対象です。対象列の`[合計, 最大値, 最小値, 平均値]`を表示します。

    - **棒グラフ**：  
      対象列のすべての値の出現頻度を表示します。  
      横軸：値  
      縦軸：回数

    - **ドーナツチャート**：  
      対象列の各値の出現割合を表示します。

### 検索欄

検索欄①に値を入力して検索します。検索方式は**完全一致**であり、各行のいずれか1つでも完全一致する値があれば検索結果に含まれます。

入力時には150msのデバウンス処理が適用されます。

検索欄右側②には、条件に一致した行数が表示されます。

### 項目内容

![image](https://github.com/user-attachments/assets/436e452a-b1d1-4ec7-83ef-71f5e97fda04)

#### 閲覧モード

[グリッドビュー](#ビュー欄)で画像をクリックする、または[テーブルビュー](#ビュー欄)で行をクリックすると閲覧モードへ入ります。

その行に対応する画像が存在する場合、左側の画像領域①および背景に表示されます。

行内のすべての列とその対応する値は右側に縦方向で表示されます。

#### 編集モード

[閲覧モード](#閲覧モード)で右上の鉛筆アイコン②をクリックすると編集モードへ入り、各列に対応する値を編集できます。

- `Boolean`型：スイッチとして表示され、クリックで切り替えできます。
- `Tag`型：ドロップダウン選択ボックスとして表示されます。[列定義](#メインテーブル設定--サブテーブル設定)の**列値プリセット**に含まれる値が選択肢として表示されるほか、自由入力も可能です。
- `Number`型：数値入力欄として表示されます。
- `Text`型：テキスト入力欄として表示されます。
- `Paragraph`型：同様にテキスト入力欄として表示されますが、改行を含めることができます。  
  改行は`\n`などのエスケープ文字ではなく、キーボード入力で直接行ってください。

#### 項目を削除

[閲覧モード](#閲覧モード)で右上のゴミ箱アイコン③をクリックすると現在の行を削除できます。

現在の行にサブテーブルが存在する場合、**サブテーブルも同時に削除されます**。
